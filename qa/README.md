# الفحص والاختبارات

اختبارات آلية تتأكد أن كل شيء يعمل قبل أي نشر. **لا تتصل بأي بيانات حقيقية**: كل طلب خارج الجهاز (Firebase، Google…) يُلغى أثناء الاختبار.

## ماذا تفحص
- البرنامج يفتح بدون أخطاء على شاشة الدخول.
- حساب الوصل (المجموع، الخصم)، الفاتورة (الضريبة 19%، الباقي بعد الدفعات)، والقياسات (م²، م.ط، م³، العواميد، الدوائر، الزوايا).
- عرض الوصل وطباعته A4 ببيانات وهمية في الذاكرة فقط، والحماية من تشغيل كود عبر اسم الزبون.
- شريط التمرير على اليمين بالكمبيوتر، ولا تمرير أفقي على الجوال.

## التشغيل على جهازك
```powershell
cd qa
npm ci
npx playwright install chromium
npx playwright test
```

## الأخطاء المعروفة
الاختبارات المعلّمة بـ `test.fail` تصف خللاً موجوداً ينتظر الموافقة على إصلاحه. عند إصلاحه سينبّه الاختبار لإزالة العلامة.

التشغيل التلقائي على GitHub موجود في `.github/workflows/qa.yml`.
